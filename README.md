# blackjack-cli
Карточная игра "Блэкджек", написанная на Go.

---

### Особенности реализации
* **Полный набор правил:** Реализованы механики разделения рук (Split), удвоения (Double), страховки от туза у дилера (Insurance), сдачи (Surrender) и прочие механики.
* **Smart Save/Load:** Автоматическое сохранение прогресса в JSON-файл домашней директории и безопасное чтение баланса.
* **ASCII UI:** Красивая отрисовка карт прямо в терминале с поддержкой ANSI-цветов для мастей.

---

### 🚀 Быстрый старт

Убедитесь, что у вас установлен компилятор Go (желательно версии 1.27 или новее, но в теории должно работать на 1.22+).

1. Склонируйте репозиторий:
```bash
git clone https://github.com/svx-dachshund/blackjack-cli.git
cd blackjack-cli
```

2. Запустите игру:
```bash
go run blackjack.go
```

Доступные флаги при запуске:
* `-log` — включить логирование ходов в файл `blackjack.log`.
* `-reset` — сбросить текущий сохранённый баланс и начать заново.
* `-player int` — задать кастомный стартовый баланс игрока.
* `-dealer int` — задать кастомный стартовый баланс дилера.
